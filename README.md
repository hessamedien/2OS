# OS Simulator v2.0 - Enhanced Desktop Experience

## 🚀 Project Overview
**OS Simulator v2.0** is an advanced, visually stunning desktop operating system simulator built with Python and Pygame. This fan-created project simulates two major operating systems (Windows 11 and macOS) with remarkable attention to detail, providing an interactive demonstration of modern UI/UX design principles.

## ✨ Key Features

### 🖥️ Dual OS Simulation
- **Windows 11 Interface**: Modern Fluent Design with transparent effects, rounded corners, and taskbar
- **macOS Interface**: Sleek dark mode design with Dock and menu bar
- **Boot Screen**: Custom boot loader with animated progress indicators

### 📱 20+ Interactive Applications
1. **Browser** - Modern web browser simulation with address bar and navigation
2. **Settings** - System configuration panel with categories
3. **Terminal** - Command-line interface with simulated commands
4. **Music Player** - Audio player with album art and controls
5. **Calculator** - Scientific calculator with modern UI
6. **Notes** - Note-taking application with rich text
7. **Calendar** - Interactive monthly calendar
8. **App Store** - Application discovery platform
9. **Game** - Space adventure mini-game
10. **Camera** - Camera application with multiple modes
11. **Gallery** - Photo gallery with grid view
12. **Social Media** - Facebook, Instagram, Twitter, Telegram, WhatsApp
13. **Weather** - Weather forecast with 5-day outlook
14. **Mail** - Email client with inbox view
15. **Maps** - Interactive map with landmarks
16. **Files** - File manager with sidebar navigation
17. **Video Player** - Media player with playback controls

### 🎨 Advanced UI Elements
- **Modern Window Management**: Draggable, resizable, minimizable windows
- **Context Menus**: Right-click context menus throughout the OS
- **Animated Transitions**: Smooth loading animations and effects
- **Dynamic Backgrounds**: Parallax and gradient backgrounds
- **Hover Effects**: Interactive UI elements with visual feedback
- **System Tray**: Time display and system indicators

## 🛠️ Technical Implementation

### Dependencies
```bash
pip install pygame requests
```

### Project Structure
```
OS-Simulator/
├── assets/                 # Image resources and icons
├── 2OS.py                 # Main application file
└── README.md              # Documentation
```

### Running the Simulator
```bash
python 2OS.py
```

### Controls
- **ESC**: Exit/Go back
- **F1**: Toggle help screen
- **F2**: Toggle language (English/Farsi)
- **F11**: Toggle fullscreen
- **Mouse**: Primary interaction
- **Right-click**: Context menus
- **1-4**: Boot menu selection

## ⚙️ System Requirements
- Python 3.8+

- 1920x1080 resolution recommended
- 100MB free disk space
